# 🎓 Laravel Course Management Platform

A robust, web-based course management platform built with **PHP** and the **Laravel framework**. Designed with traditional web authentication and Blade templating to provide a seamless user experience for online learning and course administration.

---

## ✨ Features

- **User Authentication:** Secure registration, login, and logout system utilizing Laravel's web session management (`auth` middleware).
- **Course Management:** Protected routes and structured controllers for managing and viewing educational courses.
- **Responsive Views:** Clean and user-friendly interface built using modern Laravel Blade templates.
- **Database Integration:** Integrated with MySQL to securely store user credentials, sessions, and platform data.

---

## 🛠️ Tech Stack

- **Backend:** PHP, Laravel Framework
- **Frontend:** Blade Templates, HTML5, CSS (Bootstrap)
- **Database:** MySQL
- **Version Control:** Git & GitHub
